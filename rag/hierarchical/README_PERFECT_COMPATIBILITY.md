## 🚀 **사용법**

### **1. 기본 사용 (기존 시스템과 동일)**
```python
from hierarchical import HierarchicalProcessor

# 기존 시스템과 동일한 방식으로 사용
processor = HierarchicalProcessor()
result = processor.chunk_by_articles(text)

# 모든 위계 필드와 상태 플래그가 자동으로 설정됨
for chunk, metadata in result:
    print(f"조: {metadata['article_number']}")
    print(f"생략: {metadata['is_omission']}")
    print(f"개정: {metadata['is_amendment']}")
```

### **2. 고급 사용 (Phase 1, 2 기능 활용)**
```python
from hierarchical import PatternScanner, SinglePatternProcessor

# 패턴 스캔
scanner = PatternScanner()
patterns = scanner.scan_line("제1조(목적) ... 생략 ...")

# 단일 패턴 처리
processor = SinglePatternProcessor()
result = processor.process_pattern(patterns[0], context)

# 상태 플래그 자동 감지
print(f"생략 여부: {result.chunks[0].metadata['is_omission']}")
```
